# Blogger SEO settings and theme checklist

These one-time Blogger changes complement the repository's publishing checks.

## Worth Buying UK

- Blog language: English (United Kingdom).
- Search description: `UK buying guides, product comparisons and genuine deals across technology, home, motoring and more. Discover what is really worth buying.`
- Theme: use the post title as the only `h1` on item pages; use the homepage hero heading as the only `h1` on the homepage.
- Theme structured data: publisher name `Worth Buying UK`, not `Blogger`.

## Worth Buying USA

- Blog language: English (United States), so the document language is `en-US`.
- Search description: `US buying guides, product comparisons and genuine deals across technology, home, motoring and more. Discover what is really worth buying.`
- Footer About link: `/p/about-worth-buying-usa.html`.
- Theme: use the post title as the only `h1` on item pages; use the homepage hero heading as the only `h1` on the homepage.
- Theme structured data: publisher name `Worth Buying USA`, not `Blogger`.

## Editorial requirements for every article

- Add a unique search description of roughly 120–155 characters in Blogger's post Search Description field.
- Use a single descriptive `h1`, followed by `h2` sections and `h3` product entries.
- Replace blank or generic image alt text with a concise description of the pictured product.
- Explain who each choice is for, what trade-off it makes, and what the buyer should verify.
- Localise UK and US versions; do not publish near-identical market copies.
- Keep affiliate links marked `rel="sponsored nofollow"` and disclose the commercial relationship clearly.
- Do not publish a page solely because a keyword is available. Publish only when it adds a useful comparison or decision aid.

## Search Console follow-up

- Submit each site's sitemap and inspect the homepage plus priority guides.
- Request indexing only after the final page is live and internally linked.
- Review queries, impressions, clicks and average position monthly; improve pages with impressions but weak click-through rate before creating more near-duplicate pages.
